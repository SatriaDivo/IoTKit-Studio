# Features Documentation

Dokumentasi untuk fitur-fitur di IoTKit-Studio.

## 📚 Daftar Fitur

### 🎯 Core Features

1. **Projects Management**
   - Create, edit, delete projects
   - Project configuration (protocol, host, port, etc.)
   - Project status monitoring

2. **Payload Builder**
   - Visual payload field builder
   - Multiple data types (string, number, boolean, object, array)
   - Generation modes (static, random, incremental, timestamp)
   - Import/export JSON
   - Template management

3. **Simulation**
   - Real-time simulation
   - Start/stop simulation
   - Interval and batch size configuration
   - Live statistics

4. **Logs & Monitoring**
   - Real-time logs
   - Filter by type, protocol, status
   - Pagination
   - Export logs

5. **Dashboard**
   - Overview statistics
   - Protocol usage chart
   - Recent activity
   - Real-time updates

### 🤖 AI Features

6. **AI Agent** → [../ai/](../ai/)
   - Autonomous project creation
   - Natural language processing
   - Multi-language support (Indonesian & English)
   - Real-time task execution

### 📊 Analytics

7. **Analytics Dashboard** (Coming Soon)
   - Data visualization
   - Performance metrics
   - Trends analysis
